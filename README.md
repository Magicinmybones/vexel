# Vexel

A responsive landing page for Vexel, built as a dependency-free static site.

## Structure

- `public/index.html` — deployable page
- `public/assets/` — local fonts and hero artwork
- `wrangler.jsonc` — Cloudflare Pages configuration

## Local preview

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```
